## Projects

- **Online Appointment Booking System - Business Analysis (Jira + Confluence)**<br>
  Created a business analysis case study for an online appointment booking system for a network of private physiotherapy clinics. Identified key problems related to manual, multi-channel appointment handling and defined business goals, project scope and stakeholder needs. Modeled AS-IS and TO-BE business processes using swimlane diagrams. Created Epics, User Stories and BDD-style Acceptance Criteria (GIVEN / WHEN / THEN). Documented the project in Confluence and managed the backlog in Jira.

- **Customer Support Ticket Management (BPMN)**<br>
  Modeled an end-to-end customer support ticket handling process using BPMN 2.0, including AS-IS and TO-BE states. Designed a support workflow with clear separation between first-line and second-line support. Included SLA monitoring, escalation logic and customer confirmation before ticket closure. Used subprocesses to model second-line investigation and resolution activities. Defined key KPIs such as SLA compliance, resolution time, escalation rate and reopen rate. Created the process documentation using ADONIS:CE.

- **Pizza Ordering Process Modeling (BPMN)**<br>
  Modeled an end-to-end pizza ordering process using BPMN notation. The diagram focuses on roles and responsibilities as well as key decision points (delivery vs. pickup and cash vs. card payment). The process model was created using draw.io.  
  *Note: The BPMN diagram and project documentation are prepared in Polish.*

- **SQL Business Analysis**<br>
  Built a PostgreSQL-based e-commerce database to analyze customer behavior and order statuses. Created analytical SQL queries using joins, aggregations and date functions to answer common business questions and support reporting.

- **Product Data Quality Checks (Excel)**<br>
  Validated product data fields including quantity, discount rates and product identifiers. Implemented error flagging and summary reporting to support data quality analysis.
